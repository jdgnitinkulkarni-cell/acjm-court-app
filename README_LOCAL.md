# ACJM Court App - Local Run

This package is based on the Emergent/GitHub solution and has been adjusted to run locally.

## Start

Double-click:

`start-court-app.bat`

Then open:

`http://127.0.0.1:8000`

## Default Logins

Admin password: `ahmedabad@2026`

Staff login: `Staff`

Staff password: `Staff@123`

## Local Storage

The backend stores court details, staff users, plea entries, Excel upload, Primary FS, and Final FS records in:

`backend/local_data.json`
